My rule for every project: if I can't measure it, I don't trust it. So every repo below ships with real benchmark numbers, not vibes.

### 🛠️ Things I've built

**🗄️ [MCP Data Assistant](https://github.com/abraar64mak/MCP-DATA-ASSISTANT)**
Ask your database a question in plain English, get safe SQL back. The fun part was making it hard to break: every query gets parsed and checked before it touches the database, and row-level security does the rest.
> 75% execution accuracy · refused 6/6 adversarial prompts · 5.7s median response

**📄 [Document Intelligence Platform](https://github.com/abraar64mak/document-intelligence-platform)**
Turns messy business documents into clean, structured data. Transformers for extraction, PySpark to run it at scale, FastAPI to serve it.
> 0.9155 strict entity F1 on CoNLL-2003 (3,453 documents)

**⚖️ [Distributed Code Judge](https://github.com/abraar64mak/Distributed-Code-Judge)**
A LeetCode-style judge that runs untrusted code in isolated containers, with Kafka queuing submissions behind the scenes.
> Docker · Kafka · PostgreSQL · GitHub Actions

**🫀 [ECG Fiducial Point Detection](https://github.com/abraar64mak/ECG-FUDICIAL-POINT-DETECTION)**
Finds the exact start, peak, and end of every P, QRS, and T wave in a heartbeat, the landmarks cardiologists measure by hand. Built with a 1D U-Net and a TCN bottleneck, trained on LUDB and PTB-XL.
> 1D U-Net · TCN · ONNX · 42% faster inference
